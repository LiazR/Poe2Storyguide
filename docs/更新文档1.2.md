## 配置更新

### 章节注册

`content/manifest.json` 新增 Act 5 条目：

```json
{ "id": "act5", "title": "Act 5", "file": "/content/chapters/act5.json" }
```

### 内容加载注册

`src/data/loadContent.ts` 新增 act5 的静态 import 和 Record 映射：

```ts
import act5 from "../../content/chapters/act5.json";

const chapters: Record<string, Chapter> = {
  "/content/chapters/act5.json": act5 as Chapter,
};
```

### 节点名称映射

`src/data/nodeNames.ts` 新增 Act 5 的 22 个节点名称映射，支持国际服/国服名称切换。

映射来源：`docs/info5.md` 中的节点标题格式（括号前为国际服名称，括号内为国服名称）。

### 首页统计

`src/pages/HomePage.tsx` 首页统计数据"已整理章节"从 `"4"` 更新为 `"5"`。

## 编写规范

本次第五章攻略内容编写遵循以下规则：

- 攻略内容直接取自 `docs/info5.md`，不做美化或改写
- `description` 中每句话末尾使用 `\n` 换行
- 多步骤内容拆分为 `steps` 数组
- `hint` 从攻略内容中提炼精简提示
- `title`、`mapTitle` 不包含括号内的国服名称（国服名称由 `nodeNames.ts` 统一管理）
- `badge` 仅在 info5 中明确标注 JSON 块的节点添加

## 注意事项

当前项目为了支持离线双击打开，章节 JSON 会被打包进 JS。新增章节时，只改 `manifest.json` 不够，必须同时在 `loadContent.ts` 中添加 import 和映射，否则运行时会抛出"无法加载章节"错误。
