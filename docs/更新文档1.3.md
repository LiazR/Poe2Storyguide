# 更新文档 1.3

## 版本概览

本次更新新增赛季任务说明模块（SeasonQuestPanel），并在前四章（Act 1-4）中植入了符文赛季任务数据。同时修复了 Tailwind CSS 语法错误、更新了内容填写指南。

## 新增功能

### 赛季任务说明面板（SeasonQuestPanel）

为右侧详情面板新增赛季任务查看功能。每个章节可配置 `seasonQuests` 数组，通过 tab 切换查看不同赛季任务分组。

**组件文件**：`src/components/SeasonQuestPanel.tsx`

**数据结构**（`src/types/content.ts`）：

```ts
export interface SeasonQuestStep {
  title: string;
  body?: string;
}

export interface SeasonQuest {
  id: string;
  title: string;
  overview: string;
  steps: SeasonQuestStep[];
  reward?: string;
  note?: string;
}

// Chapter 接口新增字段
export interface Chapter {
  // ... 原有字段
  seasonQuests?: SeasonQuest[];
}
```

### 视觉与交互设计

- 赛季按钮位于右侧详情面板右上角，对标左上角进度指示
- 按钮 UI 与"下一步"按钮一致（btn-primary 样式）
- 展开时显示 ▼ 箭头，收起时显示 ▶ 箭头
- 展开内容位于 `seasonReward`（赛季玩法奖励）绿色框下方、攻略描述文字上方
- 赛季内容区域使用绿色圆角边框 + 深绿色背景，与灰色攻略正文明显区分
- 支持多 tab 切换（圆角标签页），tab 区域横向滚动
- 步骤列表使用圆形序号标记，含步骤标题和正文
- 底部可选显示奖励汇总（绿色框）和注意事项（黄色框）
- 内容区最大高度 320px，超出滚动

**CSS 样式**：位于 `src/index.css` 文件末尾，类名前缀 `season-`。

### 赛季任务数据传递

`src/pages/GuidePage.tsx` 传递 `seasonQuests` 给 `NodeDetail` 组件：

```tsx
<NodeDetail
  // ... 其他 props
  seasonQuests={chapter.seasonQuests}
/>
```

## 问题修复

### Tailwind CSS 语法错误

**错误信息**：`Missing opening {`（Pre-transform error）

**原因**：之前插入 season CSS 样式时，在 `@media (max-width: 480px)` 媒体查询块内多引入了一个多余的 `}`，导致该媒体查询块提前闭合，后续的 `.marker-pin`、`.marker-num` 等规则变成孤立代码。

**修复方式**：移除多余的 `}`，将 season CSS 样式移至文件末尾（所有 `@media` 块之后）。
