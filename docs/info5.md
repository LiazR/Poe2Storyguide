# 1.林間空地(林间空地)

建议59级以内完成间章。因为等级54-59会减40全抗。60-64会减50全抗

此章节后续会随版本修改，同时基本属于线性任务一路打过去即可

**建议优先去林間空地**

好处除了天赋点会多2天赋点+40精魂+npc给传奇

# 2.灰燼森林(灰烬森林)

赛季玩法奖励：随机稀有腰带

(可选)此处有个纪念碑会给高等级技能宝石。

建议直接到克里亚村(下张图)

# 3.庫萊亞村(克里亚村)

赛季玩法奖励：随机符文

击杀完boss后会给**剧情属性**40精魂和精魂宝石

```json
"badge": { "text": "+40精魂", "type": "`skill`" },
```

# 4.冰川湖泊(冰川池塘)

赛季玩法奖励：高阶增幅石

在冰冻利爪boss前有个狂嗥洞穴

然后去库莱亚山巅

# 5.狂嗥洞穴(嚎叫洞穴)

赛季玩法奖励：混沌石

击杀boss得**2点剧情天赋**

```json
"badge": { "text": "+2天赋", "type": "`skill`" },
```

# 6.庫萊亞山巔(克里亚峰)

赛季玩法奖励：高阶蜕变石

此处记得找左斜上方处npc领取免费传奇物品

# 7.蝕刻溪谷(刻蚀峡谷)

赛季玩法奖励：崇高石

击杀boss进入下张图

# 8.庫阿西克寶庫(库阿奇克宝库)

赛季玩法奖励：瓦尔宝珠

直接击杀boss后回城找黑衣人去往卡里市集(卡莉集市)

# 9.卡里市集(卡莉集市)

**卡莉集市**最终boss为王子(需要熟练度如果觉得不好打。可开完奇玛尔水库回城找黑衣人去往奥格姆(避难所))

往斜右上处出口进卡里交匯道

# 10.卡里交匯道(卡莉渡口)

赛季玩法奖励：宝石匠棱镜

boss打完得(**2点剧情天赋**)在斜上右上方处打完不急着回城

```json
"badge": { "text": "+2天赋,5%hp", "type": "`skill`" },
```

正上方处有骨颚阶梯拿**剧情属性**永久5%生命上限

斜左上放 賈萊關口传送点

最左侧处进入卡塔爾之塘

# 11.卡塔爾之塘(卡哈塔之池)

赛季玩法奖励：点金石

地图呈U型直接下张图即可

# 12.塞爾卡里庇護所(塞卡莉圣所)

赛季玩法奖励：机会石

①(建议拿)此处掉落硬币在右边推荐换项链有几率出法术/投射物/召唤等级的项链

②击杀完boss后不用回城一路靠传送点回到卡哈塔之池—>卡莉渡口—>贾莱关口传送点



# 13.賈萊關口(加莱之门)

赛季玩法奖励：高阶增幅石

boss打不过记得带火抗戒指。击杀完boss后到奇玛(下张图)

# 14.奇瑪(奇玛尔)

赛季玩法奖励：崇高石

①离入口不远处就会有5个buff选项柱

```json
"badge": { "text": "永久增益", "type": "`loot`" },
```

②斜右上方即是奇玛水源地

# 15.奇瑪水源地(奇玛尔水库)

赛季玩法奖励：高阶蜕变石

此处如果觉得一路过来的boss打的比较艰难推荐开完奇玛尔水库回城找黑衣人去往奥格姆(避难所)

①(可选)收集任务道具放入3个水池

②最终boss打完后回城找黑衣人去往奥格姆(庇护所)



# 16.庇護所（避难所）

进入火噬農地

# 17.火噬農地(焦土农田)

赛季玩法奖励：4级辅助宝石

①在斜上放记得开传送点(需打完瑟尔之石boss后开启)

②建议先击杀寒冰boss再击杀火焰boss

# 18.瑟雷之石(瑟尔之石)

赛季玩法奖励：崇高石

沿着边缘开完石阵一圈后回到中间石阵击杀boss后回到火噬農地斜上方传送点

# 19.黑木林(黑木林)

赛季玩法奖励：高阶蜕变石

沿着走去往霍爾登

# 20.霍爾登(霍尔顿)

赛季玩法奖励：随机符文

①往斜上方去往狼之要塞

②(可选)此图的运河处有npc出售高级符文(2000金币)可都买

③斜下方前往霍尔顿庄园
